# Expense Tracker (Android) — Koin + Room

An Android expense-tracking app built in **Kotlin** with local persistence via **Room** and dependency injection via **Koin**. Add, categorize, and review your expenses — fully offline.

## Features
- Add, edit, and delete expense entries
- Categorize expenses and review running totals
- Local persistence with Room (works offline)

## Tech Stack
- **Language:** Kotlin
- **Architecture:** MVVM
- **Local Storage:** Room
- **Dependency Injection:** Koin
- **Async:** Coroutines & Flow
- **Build:** Gradle (Kotlin DSL)

## Getting Started
1. Clone: `git clone https://github.com/Muhammad-Umer-Android/Expense_Tracker_Koin_Room.git`
2. Open in Android Studio and let Gradle sync.
3. Run on an emulator or device.
